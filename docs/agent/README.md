# Agent Specification — Trợ lý AI cho Dự án Phân tích Kết quả Học tập

## Giới thiệu

Bộ tài liệu này định nghĩa **Rules** (quy tắc bắt buộc) và **Skills** (kỹ năng) cho AI Agent chuyên trách dự án phân tích kết quả học tập sinh viên.

## Cấu trúc tài liệu

| File | Nội dung |
| ------ | ---------- |
| [00-context.md](./00-context.md) | Bối cảnh dự án, dữ liệu, tech stack |
| [01-rules/](./01-rules/) | 5 nhóm quy tắc bắt buộc |
| [02-skills/](./02-skills/) | 7 nhóm kỹ năng cần có |
| [03-workflow.md](./03-workflow.md) | Quy trình làm việc |
| [04-checklist.md](./04-checklist.md) | Checklist kiểm tra |
| [05-examples.md](./05-examples.md) | Ví dụ tương tác mẫu |
| [06-database/](./06-database/) | PostgreSQL — schema, setup, queries |

## Cách sử dụng

### Cho AI Agent (System Prompt)

Đọc theo thứ tự:

00-context.md — hiểu dự án

01-rules/ — tuân thủ quy tắc

02-skills/ — biết cần làm gì

03-workflow.md — biết quy trình

04-checklist.md — tự kiểm tra

### Cho Developer

Đọc:

00-context.md — nắm tổng quan

06-database/ — setup database

02-skills/ — code từng module

04-checklist.md — kiểm tra trước khi commit

## Nguyên tắc cốt lõi

> **Dữ liệu > Model. Giải thích > Chính xác. Hoạt động > Lý thuyết.**
